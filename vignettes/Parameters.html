ProteoMaker Pipeline Parameters

This vignette describes the parameters used by ProteoMaker. The parameters are split into two groups:

  • set_proteomaker() controls paths, parallelization, and which downstream work is run.
  • def_param() returns the simulation parameters used by the pipeline stages.

Parameter Flow

Summary

Configuration from set_proteomaker()

These parameters are not part of the simulation hash. They control where files are read and written, how much parallelism is used, and whether optional downstream steps run.

Parameter Default Purpose
fastaFilePath package Proteomes folder Directory containing FASTA files referenced by PathToFasta.
resultFilePath SimulatedDatasets Output directory for cached simulation stages and benchmark results.
cores 2 Number of CPU cores used by parallel steps.
clusterType PSOCK Parallel cluster backend, usually PSOCK or FORK.
runStatTests TRUE Run statistical tests after simulation.
calcAllBenchmarks TRUE Calculate benchmark summaries after statistical testing.

Using the Parameters

Use set_proteomaker() once for runtime configuration and def_param() for the simulation design.

Code 
config <- set_proteomaker(
  fastaFilePath = system.file("Proteomes", package = "ProteoMaker"),
  resultFilePath = file.path(tempdir(), "SimulatedDataSets"),
  cores = 1,
  clusterType = "PSOCK",
  runStatTests = TRUE,
  calcAllBenchmarks = TRUE
)

Param <- def_param()
Param$paramGroundTruth$PathToFasta <- "fasta_example.fasta"
Param$paramGroundTruth$NumCond <- 2
Param$paramGroundTruth$NumReps <- 3

Each top-level element in Param corresponds to one pipeline stage. Parameters can be vectors; run_sims() expands them into combinations.

set_proteomaker() Configuration

Paths

Parameter Description
fastaFilePath Directory containing FASTA files. PathToFasta values from Param$paramGroundTruth are resolved relative to this directory.
resultFilePath Directory used for saved stage files, retrieved simulations, and benchmark tables. The directory is created if needed.

Runtime

Parameter Description
cores Number of cores used by parallelized steps. Larger values can substantially increase RAM use.
clusterType Parallel backend. PSOCK is portable; FORK can be faster on Unix-like systems but is not available everywhere.
runStatTests If FALSE, simulation can stop before statistical testing and occupancy/benchmark calculation.
calcAllBenchmarks If TRUE, benchmark metrics are calculated after statistical testing.

def_param() Simulation Parameters

The tables below follow the actual top-level lists returned by def_param(). Defaults and ranges are read from inst/config/parameters.yaml.

paramGroundTruth: Ground Truth and Experimental Design

Define the input proteome, experiment layout, expressed proteins, and PTM ground truth.

Experimental Design

Parameter Default Range Description
ProteoMakerVersion dev NA - NA Keeping version to ensure reproducibility. Automatically set when running simulation.
NumCond 2 1 - 10 Number of conditions.
NumReps 3 1 - 10 Number of replicates.

Input Data

Parameter Default Range Description
PathToFasta fasta_example.fasta NA - NA Path to input FASTA file.
PathToProteinList NA NA - NA Path to input protein list (optional).

Ground Truth Data

Parameter Default Range Description
PercExpressedProt 1 0 - 1 Fraction of expressed proteins from fasta file.
FracModProt 0 0 - 1 Fraction of proteins selected to be modified (0 for none, 1 for all).
PropModPerProt 1 1 - 500 Multiplier for generating additional modified proteoforms per selected protein. Values >= 1 create distribute that many independently modified proteoforms per protein.
PTMMultipleLambda 0 0 - 10 Lambda for the truncated Poisson distribution (truncated to [1, N]) controlling the number of modification sites per proteoform.
RemoveNonModFormFrac 0 0 - 1 Fraction of modifiable proteins for which the unmodified proteoform is removed.
PTMTypes NA NA - NA Types of post-translational modifications (PTMs). Use a list such as list(mods=c(“ph”)
PTMTypesDistr NA 0 - 1 Distribution of PTM types. This means how much of which PTM type is present. Given as named list of values that sum up to 1.0.
PTMTypesMass NA 0 - 200 Mass shifts for each PTM type. Also given as named list for the same simulation
ModifiableResidues NA NA - NA Residues that can be modified for each PTM type. Given as a named list of strings, each list element representing a PTM type and the residues.
ModifiableResiduesDistr NA 0 - 1 Distribution of modifications across residues. Same layout as for PTMTypesDist.

Parameter Default Range Description

paramMSRun: MS Run and Search

Simulate detection, missing values, instrument noise, false IDs, and localization errors.

MS Run

Parameter Default Range Description

WeightDetectVal 1 0 - 50 Weights for intensity-dependence of non-detection.

MS Search

Parameter Default Range Description

WrongLocalizations 0 0 - 0.1 Fraction of wrong localizations.

MS Search Results Filter

Parameter Default Range Description
MaxNAPerPep 100 0 - 100 Maximum number of NA values per peptide allowed.

paramDataAnalysis: Data Analysis

Control protein summarisation and statistical testing.

Protein Summarization

Parameter Default Range Description
SharedPep FALSE FALSE - TRUE Include shared peptides in summariation
ProtSummarization medpolish NA - NA Method for summarizing to proteins (sum.top3, median, mean, sum, medpolish or rlm). sum and sum.top3 are on absolute scale, not on log2.
MinUniquePep 1 1 - 10 Minimum number of unique peptides available.
IncludeModPep FALSE FALSE - TRUE Include modified peptides in summarization

Statistical Testing

Parameter Default Range Description

PTM Setup Recipe

This minimal phosphorylation setup keeps the unmodified counterpart and creates approximately one modified site per modified proteoform.

Code 
Param$paramGroundTruth$FracModProt <- 0.5
Param$paramGroundTruth$PTMTypes <- list(mods = c("ph"))
Param$paramGroundTruth$PTMTypesMass <- list(ph = 79.966331)
Param$paramGroundTruth$PTMTypesDistr <- list(ph = 1)
Param$paramGroundTruth$ModifiableResidues <- list(mods = list(ph = c("S", "T", "Y")))
Param$paramGroundTruth$ModifiableResiduesDistr <- list(
  mods = list(ph = c(S = 0.86, T = 0.13, Y = 0.01))
)
Param$paramGroundTruth$PTMMultipleLambda <- 0
Param$paramGroundTruth$PropModPerProt <- 1
Param$paramGroundTruth$RemoveNonModFormFrac <- 0

Practical Notes

  • Use set_proteomaker() for filesystem and runtime settings.
  • Use def_param() for anything that should define a simulated dataset.
  • Keep small parameter grids while testing; each vector-valued parameter multiplies the number of simulations.
  • PathToFasta names a FASTA file, while fastaFilePath names the directory that contains it.
